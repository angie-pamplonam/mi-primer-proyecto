# 📊 Análisis y Predicción de Riesgo de Diabetes

Durante mi formación en Análisis para la Ciencia de Datos, cree este proyecto (aplicación web interactiva) que está diseñado para explorar datos de salud y evaluar factores de riesgo asociados a la diabetes a partir de variables clínicas e indicadores clave y como otros factores con efecto inverso son protector del desarrollo de la patología.

---

## 🚀 Características del Proyecto

* **Filtros Dinámicos:** Selección de rangos de edad e Índice de Masa Corporal (IMC) en tiempo real.
* **Exploración de Datos:** Tabla interactiva para consultar los registros filtrados del dataset.
* **Métricas Clave:** Cálculo automático del total de registros y promedios según los filtros aplicados.
* **Interfaz Intuitiva:** Desarrollado con Streamlit para una navegación fluida.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Python 3.x
* **Librerías principales:** 
  * `streamlit` — Creación de la interfaz web interactiva.
  * `pandas` — Procesamiento y manipulación de datos.
  * `matplotlib` / `seaborn` — Visualización de gráficos.
